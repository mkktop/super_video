# Agent 记忆备份（2026-10-19，重装系统前归档）

这里是从 ZCode 助手的持久记忆目录复制出来的项目知识库（64 个 md，含索引
`MEMORY.md`）。内容是跨会话积累的项目决策、踩坑结论与环境事实——属于
「代码和 git 历史里查不到」的部分，重装系统会随 C 盘丢失，故入库存档。

## 恢复方法

重装后把本目录下的所有 `.md` 复制回记忆目录（用户名按新系统调整）：

```
C:\Users\<用户名>\.zcode\cli\memories\projects\super_video-c61c138e73fd7c1d\memory\
```

目录名里的 `super_video-c61c138e73fd7c1d` 是工作区路径对应的项目键；若新环境
生成的键不同，以新键目录为准放入即可，文件内容自包含。

## 维护约定

- 这份备份是**快照**不是镜像：恢复后以记忆目录为工作副本，本目录不会自动同步。
- 每条记忆一个文件，`MEMORY.md` 是索引（每条一行）。新增/修改记忆时同步索引。
- 敏感性：已扫描确认不含任何 token/密钥明文（引用的 MODELSCOPE_TOKEN 等均为
  GitHub CI secret 名，非值）。
